Tracker

sharerr serves announces itself, from this instance, whichever torrent client seeds. It answers only for torrents sharerr made.

{% call locked("tracker.advertised_host") %}{% endcall %}

Required. sharerr cannot guess its own externally reachable address, and a wrong value silently produces torrents nobody can announce to.

{% call locked("tracker.port") %}{% endcall %} {% call locked("tracker.advertised_url") %}{% endcall %}

For reverse-proxied or IPv6 setups: a full base URL with scheme and any path prefix. When set, it wins over the host and port above.

{% if tracker_token_set %} {% endif %}

When set, the token is embedded in every announce URL, so holding the .torrent is what grants the right to announce. Changing it invalidates torrents already published — leave it alone unless you mean to cut off existing peers.

sharerr is serving its own tracker on this instance.

Gluetun

Behind a VPN with a forwarded port, the address friends reach you on changes on every reconnect. Point this at gluetun's control server and sharerr resolves its public IP and forwarded port from there, re-announcing and rewriting torrents when they change — instead of trusting the static address above.

{% call locked("gluetun.control_url") %}{% endcall %} {% call locked("gluetun.poll_secs") %}{% endcall %}

The poll is the safety net; for reconnects to be picked up in seconds, set gluetun's VPN_PORT_FORWARDING_UP_COMMAND to hit /gluetun/refresh on this instance.
