Backup and restore
{% call ui::doc(crate::web::docs::CONFIGURATION, "Configuration reference") %}{% endcall %}

Downloads the effective configuration — defaults, sharerr.toml, and any SHARERR_* environment overrides, merged into one file — rather than the raw file on disk, since an env-overridden field is never written to that file at all. Not included: anything in the vault (API keys, the tracker token, this instance's signing key) or the peers table (friends and their scopes). Those live in the database and vault files, untouched by this feature, and are preserved as long as those files themselves survive a move or reinstall — this only rebuilds sharerr.toml itself, the wizard's second half.
